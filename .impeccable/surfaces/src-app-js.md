# Surface: portfolio home (src/App.js) + /projects

Mode: Experience (portfolio), with a recruiter's fast path to email/resume always visible.
Audience: PM/SWE recruiters. Action: email or open resume. Proof: experience rows + 10 real projects. Constraint: all copy verbatim.

## Direction contract

THESIS: A studio-grade atmospheric portfolio in unseen.co's grammar: the page is a soft mint weather system you look *through* at the work. Refuses the category default of dark background + neon accent + card grid + skill chips.

OWN-WORLD: Pale fog ground (#E9EFEA) with a live WebGL haze of mint #C5EBC3, sea-glass, lilac and a peach warm spot, drifting and bending toward the cursor. Near-black ink #111311. Archivo (expanded, heavy) for monumental display; Geist for body; Geist Mono 11px uppercase tracked labels. No cards, no chips, no shadows: hairline rules, numbered index rows, pill buttons in ink.

STORY: Visitor sees the name at monumental scale and who she is in one line, reads the about statement lighting up word by word, scans experience as an index, hovers projects and sees each screenshot follow the cursor, ends on a giant contact line with email.

FIRST VIEWPORT: Full-bleed fog canvas. Top: fixed header (XY mark + name left, live Singapore time centre, Resume pill + Menu right). Upper-left: role cycler + one-line intro + availability line + "View work" / "Resume" pills. Bottom: "XING YING" set edge-to-edge across the full width (~19vw), ink. Portrait floats small at right, tilting with cursor. Bottom strip: "Scroll to explore" + "Singapore".

FORM: user-pinned (unseen.co reference with mint identity) over the seed roll; seed key fb12dc1a. Raise from ikebana-ma challenger (declined): charged negative space: every section keeps one large deliberate empty region, asymmetric, never centred-filler.

SIGNATURE INTERACTION: preloader counter 000→100 lifting as a curtain; cursor-following project image reveal on hover; custom cursor dot that becomes a labelled ring ("View") over work; Lenis smooth scroll; word-by-word scroll-lit about statement.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
